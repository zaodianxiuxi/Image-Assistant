# 3D 多功能工作台与 Filee 接入

日期：2026-10-28。用户已批准三维工作台 + 办公、阅读、文件处理方向。

## 已批准范围
- 真正的 Three.js 场景：文件托盘、阅读台、工具柜、创作画板、任务架；旋转、缩放、对象点击与相机靠近。保留可键盘访问的等价工具入口。
- 原图片创作整页作为独立工具，切换工具保留本次页面状态，不修改模型 API、数据库或 IndexedDB 内容。
- 文件区：本地上传、搜索、最近文件、大小格式信息，持久保存。
- 阅读区：PDF 原生阅读、完整图片预览、纯文本；其他格式明确提示转换/下载，不冒充支持。
- Filee：独立 CLI，通过 Express 调用，不嵌入 Avalonia。上传文件与输出在各自 UUID 目录，调用采用参数数组，无 shell。只展示实际可用的转换目标。
- Filee formats 返回文本（不是 JSON）；convert --json 返回转换结果。能力适配固定并验证此格式。
- 持久任务队列：排队、处理、完成、失败；重启后处理中任务标记中断；结果可阅读、下载及再次转换。无伪造百分比。
- 本轮不接 OCR、AI 文档问答、视频、Office 在线编辑；不运行真实模型调用。

## 技术与兼容
使用 React 18 + Three.js 直接集成，避免为场景升级已有 React。Three.js 懒加载，离开场景销毁 GPU 资源；WebGL 不可用显示正常工具入口。保留四主题；默认跟随已有设置。尊重减少动态效果，避免持续自动旋转。

## Filee 运行方式
在项目 .local/tools 中使用官方 Windows portable 发布，校验 SHA256，保留随包许可；不注册系统菜单、不安装系统服务。FILEE_CLI_PATH 可指定其他安装位置；未安装时上传和阅读仍可用，转换显示明确配置说明。可选引擎不静默下载。

## 验证约束
按用户要求做轻量验证：编译、文件与队列关键逻辑测试、一个真实本地图片转换和一次页面交互，不逐主题逐按钮遍历。
