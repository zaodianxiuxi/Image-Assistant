# 所选输出画幅设计说明

## 目标

让用户选择常用输出画幅，并将该选择同时应用于纯文本生成和参考图编辑。参考图只作为主体、构图、材质和风格的内容线索，不再决定输出图片的画幅。

## 画幅选项

- 正方形 `1:1`：`1024x1024`
- 电脑横屏 `16:9`：`1536x864`
- 手机竖屏 `9:16`：`864x1536`

这些尺寸符合 `gpt-image-2` 的尺寸约束：边长是 16 的倍数，比例分别为 1:1、16:9 和 9:16。

## 行为

1. 画幅选择器在纯文本生成和参考图编辑模式下始终可见。
2. 纯文本生成通过 JSON 请求的 `size` 字段提交所选画幅。
3. 参考图编辑通过 multipart `FormData` 的 `size` 字段提交相同画幅。
4. 服务端只接受上述三个尺寸；其他值返回 `400`，不会转发给 SudoCode。
5. 页面不再声称参考图继承第一张图片的画幅，而是提示输出将按所选画幅生成。

## 内容处理说明

上游模型根据参考图理解内容，再在所选输出画布中重构结果。参考图与输出画幅不同的情况下，模型可能裁切、延展背景或重新安排构图；这是保证目标画幅的预期行为。

## 测试与验证

- 为允许画幅的判断添加服务端单元测试，覆盖三个允许值和一个拒绝值。
- 为前端源码添加测试，确保三个常用比例和参考图模式下可见的画幅选择器存在。
- 运行 `npm test` 与 `npm run build`。
- 不发起会消耗 SudoCode 额度的真实图片生成或编辑请求。

## 非目标

- 不增加自定义宽高输入。
- 不对参考图进行服务端裁剪、缩放或持久化存储。
- 不改变模型、参考图数量上限、单文件上限或总上传上限。
