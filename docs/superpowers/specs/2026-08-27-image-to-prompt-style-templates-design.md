# 图片反推提示词与风格模板设计

## 目标

让用户上传一张网络参考图，提取可复用的视觉风格，输入新的画面内容后生成结构化、可编辑的完整提示词。最终提示词先进入现有提示词框供用户确认，再由用户手动生成图片。

本阶段在没有 MySQL 的环境中完整支持图片分析、提示词组合和本地风格模板。数据库风格库与系列绑定保留明确接口和迁移说明，后续接入 MySQL 时不重写核心流程。

## 用户流程

1. 用户在现有提示词区域点击“从图片提取风格”。
2. 系统打开风格提取面板，用户上传一张参考图。
3. 用户点击“分析图片”，服务端调用支持图片理解的视觉模型。
4. 面板展示第一次分析文本，分为原图内容、构图、镜头、光影、色彩、材质、艺术风格和负面要求。
5. 所有结构化字段都允许编辑。构图、镜头、光影、色彩、材质、艺术风格和负面要求允许锁定；原图内容不进入可复用风格模板。
6. 用户填写新的主体、动作和场景，点击“优化组合”。
7. 服务端调用文本模型，将新内容与当前风格字段组合为完整中文提示词。
8. 完整提示词显示在预览区。用户点击“应用到提示词”后，内容写入现有提示词框，但不自动生成图片。
9. 用户可以将当前风格保存为浏览器本地模板，并在后续图片中重复使用。

## 界面结构

左侧提示词标签旁增加“从图片提取风格”入口。入口使用图标和文字，打开独立的风格提取对话框。

对话框包含以下区域：

- 参考图：单图上传、预览、替换、分析和重试。
- 图片内容：展示模型识别的主体、动作和场景，仅供理解原图，不默认加入模板。
- 风格字段：构图、镜头、光影、色彩、材质、艺术风格和负面要求。每项包含编辑框和锁定开关。
- 新画面内容：用户输入希望生成的新主体、动作、环境和关键限制。
- 完整提示词预览：展示润色组合结果，允许再次编辑。
- 操作区：优化组合、应用到提示词、保存为风格模板。
- 本地风格库：选择、重命名、更新和删除浏览器中已保存的模板。

当 MySQL 未配置时，“绑定当前系列”保持不可用，并显示“连接 MySQL 后可用”的状态提示。其他功能不受影响。

## 结构化数据

视觉分析结果字段为：sourceContent、composition、camera、lighting、color、material、style、negativePrompt。

本地风格模板不保存 sourceContent 和参考图文件。模板保存名称、七个风格字段、lockedFields、createdAt 和 updatedAt。浏览器使用独立的 image-assistant-style-profiles 本地存储键，读取失败或数据结构无效时返回空模板列表，不影响应用启动。

## 服务端能力

新增 SUDOCODE_VISION_MODEL 环境变量。该模型必须兼容现有 OpenAI 风格的 chat completions 接口，并支持图片输入。提示词组合继续使用 SUDOCODE_TEXT_MODEL；若未配置文本模型但视觉模型同时支持文本，可由服务端明确使用视觉模型作为组合模型回退。

新增 POST /api/styles/analyze：使用 multipart/form-data 接收单张 image；沿用 20 MB 上限；只接受图片 MIME；调用视觉模型并返回 analysis 结构化对象。图片只保存在请求内存中，不写入生成图片目录或数据库。

新增 POST /api/styles/compose：接收 analysis、newContent 和 lockedFields；验证新内容和七个风格字段；调用文本模型并返回完整中文 prompt。输出不包含画幅文字，画幅仍由现有 size 参数控制。

分析器和组合器分别放在独立服务模块中，路由只负责输入校验和错误转换，便于以后替换模型或增加数据库存储。

## 本地存储与数据库扩展点

本阶段新增纯函数式本地模板模块，负责解析校验、新建、更新、重命名、删除以及转换组合接口输入。

未来 MySQL 版本增加 style_profiles 表，字段包括 id、name、七个风格字段、locked_fields JSON、created_at 和 updated_at。series 表增加可空的 style_profile_id 外键。服务端未来增加风格模板 CRUD 和系列绑定接口，前端存储适配器从 localStorage 切换为 API，不改变分析面板和组合流程。

数据库接入前不伪造服务器持久化状态。本地模板明确标记为“本地”，系列绑定入口明确保持不可用。

## 系列生成规则

数据库接入后，系列节点的最终提示词按以下顺序组合：当前节点内容、系列风格模板、角色连续性和系列全局提示词、节点额外限制。

风格模板不包含参考图原始主体，避免整个系列重复出现参考图中的人物或物品。用户在节点中显式填写的内容优先于模板中的一般描述。

## 错误处理

- 未配置视觉模型：分析接口返回明确配置提示，现有生成和编辑功能继续工作。
- 模型不支持图片输入：显示当前视觉模型无法分析图片，保留上传预览。
- 图片类型错误或超过 20 MB：在请求上游前拒绝。
- 模型返回非 JSON 或字段缺失：服务端拒绝结果并允许重试，不展示残缺分析。
- 组合失败：保留分析字段和新内容，不清空草稿。
- localStorage 不可用：模板只保留在当前页面状态，并显示未持久化状态。
- 数据库未配置：仅禁用云端风格库和系列绑定，不影响本地流程。

## 安全与隐私

- 参考图仅用于本次视觉分析，不写入本地图片目录。
- 服务端日志只记录图片 MIME、字节数、模型和请求 ID，不记录图片内容、data URL 或完整提示词。
- 上游错误信息经过现有错误响应转换，不向浏览器暴露密钥或请求头。

## 测试范围

- 视觉分析模块：请求格式、结构化解析、字段校验、非 JSON、模型错误。
- 提示词组合模块：新内容必填、锁定字段传递、画幅文字清理、模型错误。
- 路由：未配置模型、错误 MIME、大小限制、成功响应。
- 本地模板模块：保存、更新、重命名、删除、无效缓存恢复和 sourceContent 排除。
- 前端结构：入口、分析状态、结构化字段、锁定控件、新内容输入、预览、应用提示词、本地模板管理和数据库禁用状态。
- 回归：现有图片生成、图片编辑、版本链、图库和三主题测试全部保持通过。

## 非本阶段范围

- 不自动生成图片。
- 不保存参考图文件。
- 不实现 MySQL 风格模板表和系列绑定接口。
- 不支持多张参考图混合分析。
- 不提供公开分享或多人协作模板。
