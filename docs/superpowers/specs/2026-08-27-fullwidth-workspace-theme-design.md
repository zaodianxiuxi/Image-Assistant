# 全宽工作台与主题体系设计

## 目标

将 Image Assistant 从居中内容页升级为适合大屏图片创作的全宽工作台，并提供三套可持久化切换的专业主题。

## 布局

- 页面根容器不再限制最大宽度；顶部导航、状态栏、主工作区和图库使用整页宽度。
- 主工作区在桌面端使用固定 360px 左侧创作面板和可伸缩右侧画布。左侧面板在较高视口中保持可见，避免用户在输入提示词与查看结果之间反复滚动。
- 右侧画布最小高度提高，生成图片以可见面积为优先，不裁剪、不拉伸。
- 图库保持独立的全宽带状区域，桌面端根据可用宽度自动使用至少四列卡片；窄屏仍退化为单列工作区和两列图库。

## 主题

主题值为 light、dark、studio，保存在现有 image-assistant-theme 本地存储键。

- light：明亮、冷白工作台，适合日常浏览和整理图库。
- dark：深灰专业工作台，降低长时间看图的亮度干扰。
- studio：暖灰编辑室，降低纯白背景对图片色彩判断的影响。

所有颜色使用语义 CSS 自定义属性（背景、面板、文字、边框、强调、成功、危险），组件不再直接依赖具体主题颜色。顶栏主题按钮改为图标入口，点击后展示三项紧凑菜单。

## 交互与边界

- 默认主题仍为现有明亮主题；已有用户的浅色/深色设置自动兼容。
- 单击主题按钮可打开主题菜单；选择后立即生效并关闭菜单，键盘 Escape 可关闭。
- 图片生成、编辑、版本链、图库分组、预览和移动端行为不改变。
- 不引入新的第三方依赖或远程资源。

## 验证

- UI 结构测试覆盖全宽工作区、三种主题值、主题菜单和 CSS 主题变量。
- 使用 Node 测试运行器执行全量测试，并运行 TypeScript/Vite 生产构建。
- 在桌面和移动视口检查页面截图，确认画布、控制面板、主题菜单和图库没有重叠或文本溢出。
