# 创作工作台视觉改版方案

状态：用户已选择「电影创作室」方向，按此实施。

## 目标

让首页从参数表单变成易于开始创作的工作台。优先解决首屏操作被挤出、空画布过大、故事入口不明显、文字和卡片缺少层次的问题。

## 推荐方向与备选

- 推荐「电影创作室」：石墨色背景、暖白文字、琥珀色重点按钮，适合连续故事与分镜创作。通过空间、字体和画面构图建立氛围。
- 「明亮简洁」：浅色底与宽松留白，阅读轻快，但创作氛围较弱。
- 「活泼灵感站」：多色卡片与更明显的动效，探索感强，但长时间编辑容易分散注意力。

现有浅色、深色、暖色主题继续可选。尊重已保存的主题；新版结构、间距和交互反馈统一适配三种主题。

## 首页布局

1. 顶部保留品牌、主题和连接状态。空闲状态提示收紧；任务进度与错误保持清晰可见。
2. 左侧编辑区按「描述画面 → 添加参考 → 画幅 → 生成」组织。缩小无图片时的上传区，减少无效留白。生成按钮放在编辑区可见的操作栏，正文可独立滚动。
3. 中央未生成时显示创作欢迎区，以「让一个念头，成为一组画面」为主标题。提供明确的「开始故事创作」按钮，以及单张图片、诗词意境快捷入口。用原生矢量或 CSS 构成分镜示意，明确它是装饰，不当成真实生成结果。
4. 有结果时，中央完整展示图片，保留预览、下载和历史合集，不让欢迎内容抢占结果区域。
5. 扩展入口配常驻文字说明，故事创作入口突出。规划中的不可用功能降级展示，避免与可用入口争夺注意力。
6. 提示词热榜改为更易扫描的灵感卡片，保留标题、分类与应用操作，长提示词不挤占首屏。

## 故事工作台

- 标题区增加清楚的创作阶段提示：故事、角色与场景、分镜。根据现有项目数据表达进度，不制造虚假状态。
- 「没有灵感？帮我想故事」作为明显的引导卡片；折叠后仍能看出用途。
- 三个故事方向有清晰的编号、标题和主要内容层级；选中方向有明确样式。
- 角色与场景参考、分镜卡片使用一致的边框、圆角、留白；镜头编号、图片和状态优先可见。
- 编辑输入、批量生成、保存反馈与错误信息保持容易辨认。

## 交互、适配与实现边界

- 按钮提供悬停与按下反馈，抽屉短暂滑入，卡片轻微淡入；动画控制在约 160–280 毫秒，避免持续漂浮和全屏闪烁。
- 遵循系统减少动态效果偏好，保留键盘焦点和明确的禁用状态。
- 桌面控制高度和滚动区域；窄屏改为单列，工具入口横向或换行排列，操作按钮不被遮挡。
- 继续使用 React、现有图标库和 CSS，不增加动画依赖。
- 优先整理相关现有样式和提取首页欢迎组件，避免扩大主组件的职责。接口、故事数据结构、存储和模型请求流程沿用现有实现。

## 验收

- 桌面首屏能看到生成操作与故事入口；无重叠、意外横向滚动或不可达操作。
- 检查首页空状态、已有结果、故事灵感展开和分镜编辑的布局，覆盖浅色与深色主题以及窄屏。
- 浏览器验证主题切换、故事打开关闭、提示词选择和表单操作，不调用付费模型。
- 运行现有测试和构建；仅调整被新视觉布局明确替代的旧样式断言，不添加镜像实现的测试。
