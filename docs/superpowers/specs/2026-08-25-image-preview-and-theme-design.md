# 图片预览与主题切换设计

## 目标

修复不同纵横比生成图在结果画布中的放大或裁切观感，使主画布和历史缩略图均可打开完整预览；增加可记忆的浅色、深色主题切换，并补充不干扰操作的界面动画。

## 方案

- 主画布使用 `width: auto`、`height: auto`、`max-width: 100%` 与 `max-height: 100%` 显示图片，保留上游返回图的原始比例。
- 主画布和历史记录复用同一个预览弹层。点击任一图片会展示完整图片；支持关闭按钮、点击遮罩和 Escape 关闭。
- 图片加载失败时显示错误状态与重新加载按钮。重新加载只为 URL 图片添加缓存刷新参数，data URL 保持原样。
- 顶部使用太阳/月亮图标切换浅色和深色主题，并通过 `localStorage` 保存。没有保存值时遵循系统主题。
- 结果出现、主题切换、缩略图悬停与预览弹层使用 `opacity`、`transform` 的短时动画。`prefers-reduced-motion` 下禁用动画。

## 边界

不改变图片生成、编辑和画幅请求参数，也不新增服务端代理。上游 URL 已失效时界面会明确提示加载失败；后续引入 MinIO 持久化后可从根本上避免临时 URL 失效。

## 验收

- 三种支持画幅在画布和弹层中均完整显示、不拉伸、不裁切。
- 主图和历史图都能打开预览，且图片失败时可见错误状态。
- 主题选择跨刷新保留，交互动画不改变布局。
