# 故事长图与原图打包实施计划

**Goal:** 在成片预览中导出纸上故事馆排版的 PNG 长图，以及当前采用图片和故事文本的 ZIP。

**Architecture:** 只在浏览器读取当前项目快照和本地图片；纯函数负责顺序、状态、文件名、文本换行与分页，浏览器导出模块负责字体、图片解码、Canvas 与 ZIP。独立导出控件展示说明、进度、失败与取消。按需加载导出模块和 ZIP 库，不调用模型。

**Tech Stack:** React / TypeScript / Canvas / fflate / Node test。

## 已确认范围与边界

- 用户已同意成片预览增加“导出故事长图”和“打包下载”，采用纸上故事馆样式。
- 仅使用 `project.results` 当前采用版，不包含未采用候选和角色参考图。
- 长图包含标题、梗概、镜头顺序、完整构图、标题与旁白。缺图显示占位；需重拍和输入变化明确注明，不伪装成完整成片。
- 原图 ZIP 保留图片内容，按 01、02 等顺序编号，附带 UTF-8 故事说明文本，缺图和过期状态写进文本。
- 图像下载或解码失败则停止，提供镜头定位信息和重试提示。导出生成期间禁止重复点击，可取消，关闭预览时中止并释放资源。
- 长图默认宽 1080px，单张高不超过 14000px；超长内容按完整镜头分页，多个 PNG 打入 ZIP，提示实际文件格式。单个镜头过长则明确要求缩短文字。
- 仅允许同源图片路径及本地 data/blob 图；单张最多 20MB，总原图最多 120MB；限定最多 12 镜。ZIP 路径去除特殊字符，保留中文，防止重名和路径穿越。
- 本轮不付费生成。用已有六镜故事验证实际下载，解码 PNG 并检查 ZIP 内容。
