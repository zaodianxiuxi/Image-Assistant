# 空间工作台

默认入口为 `#/desk`，侧栏提供项目空间、文件库、阅读台、格式转换、图片创作和任务中心。Three.js 只在桌面加载；离开桌面释放场景资源。WebGL 不可用时仍可通过普通按钮使用工具。

## Filee 配置

本项目通过独立 CLI 接入 [Filee](https://github.com/KnifeLemon/Filee)，没有嵌入它的桌面窗口。当前本机已校验并配置官方 v2.1.0 Windows portable。

在其他电脑上：

1. 从 [官方 v2.1.0 发布页](https://github.com/KnifeLemon/Filee/releases/tag/v2.1.0) 下载 Windows portable 与 SHA256SUMS 文件，按校验值核对下载内容。
2. 将完整便携包解压到项目的 `.local/tools/filee/`，保留依赖、许可及说明文件。入口为 `filee-cli.exe`，不是 GUI 的 `Filee.exe`。
3. 或者在项目 `.env` 设置 `FILEE_CLI_PATH=C:/tools/Filee/filee-cli.exe`，然后重启服务。可执行文件路径无需附加命令参数。
4. 点击侧栏“刷新引擎状态”，连接成功后从文件的转换按钮选择格式。未安装 Filee 时仍能使用文件库、阅读和图片创作。

适配器使用 `version`、`formats <扩展名>` 和 `convert <输入> --to <格式> --output <任务目录> --json`。子进程使用参数数组，不经过 shell。可选引擎格式不会冒充已安装能力；本项目不会自动安装这些引擎。格式可用不保证每份复杂文档都能无损转换，任务会记录实际错误与警告。

Filee 原项目采用 MIT 许可，详见其 [LICENSE](https://github.com/KnifeLemon/Filee/blob/main/LICENSE)。其随包工具与可选引擎的许可应随原发行包保留。本仓库不提交 Filee 二进制。

## 数据与恢复

- `.local/workbench/index.json`：文件元数据、任务状态、输出关联、项目、笔记和阅读位置。
- `.local/workbench/files/`：以内部 ID 隔离的原文件和转换结果，显示名称不作为磁盘路径。
- `.local/workbench/jobs/`：转换临时工作目录。
- 需要迁移或备份时，停止服务后复制完整 `.local/workbench/`。
- 当前服务采用单进程串行队列；重启后中断任务标记失败，可在任务中心重新选择格式执行。不要让多个后端进程同时写同一个工作台目录。
- 文件处理在本地执行；图片创作仍按原有设置访问模型服务。

## 当前范围

支持项目资料组织、项目与文件笔记、本地文件整理、PDF/图片/文本阅读，以及 Filee 当前可用的格式转换。Office 文件先选择可用格式转换后阅读，尚未提供 Word/Excel/PPT 在线编辑、OCR 界面、全文知识库或多人同步。转换不覆盖原文件。文本预览最多读取 1 MB；完整内容可下载。

## 项目与阅读笔记

1. 进入“项目空间”创建项目，关联文件库中的资料，或在项目中直接导入。文件可关联多个项目，不会产生副本。
2. 打开资料，在右侧记录 Markdown 笔记；PDF 或文本选择文字后点击“摘录到笔记”。PDF 摘录保留页码，文本摘录保留滚动位置，点击来源可以返回原文。文本存在重复句子时，查找会定位首个匹配。
3. 笔记输入停止约 800ms 后保存到本机服务，并在浏览器保留待同步草稿。显示“已保存到本机”后再关闭；保存失败可重试。不同项目的同一文件、全局文件库的阅读笔记分别保存。
4. 另一窗口更新笔记时，会显示最新版本与当前草稿；手动合并后点击保存，不会自动覆盖。右上角可导出 Markdown，包含正文、摘录、文件名称及 PDF 页码。
5. 首页最近项目提供“继续阅读”；恢复 PDF 页码与缩放、文本滚动比例。项目总览也可以单独写笔记。

本版尚无项目删除、解除文件关联或摘录删除入口。笔记正文上限 10 万字符，最多 200 条摘录，单条最多 1 万字符；超长选区仅摘录前 1 万字符。扫描 PDF 无可选文字时提示手动记笔记；加密 PDF 提示下载原件。本版不提供 OCR、完整富文本编辑或跨设备同步。

PDF 阅读使用 `pdfjs-dist`，需要 Node.js 22.13 或以上版本。worker 随应用构建，字体、CMap、WASM 和 ICC 资源由本地服务提供。PDF.js 及适配的文本层样式采用 Apache-2.0 许可，许可副本见 `docs/third-party/pdfjs-LICENSE`。
