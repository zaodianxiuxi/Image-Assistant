# 今日提示词热榜

## 使用说明

这是项目内置的静态中文提示词精选。页面每天会按日期稳定随机展示其中 6 条，同一天刷新页面时排序不变，次日自动切换。点击热榜条目即可将完整提示词填入输入框；当前已选择的输出画幅不会被修改。

提示词推荐画幅与系统的常用输出尺寸对应：`1:1` 为 `1024x1024`，电脑横屏 `16:9` 为 `1536x864`，手机竖屏 `9:16` 为 `864x1536`。推荐画幅用于构图参考，实际生成始终以页面画幅选择器的值为准。

本合集为项目内置的原创静态精选，不依赖实时抓取或外部内容。每条均包含主体、环境、光线、镜头或视角、材质与画面控制等信息，适合作为直接生成和二次改写的起点。
